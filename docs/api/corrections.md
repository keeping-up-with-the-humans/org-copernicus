# copernicus.corrections

Human sampling of whole groups, with the fingerprint that binds a draw to its table (`copernicus.corrections.sampling`) and the draw file that keeps a draw (`copernicus.corrections.draw_files`); the sample-size planner (`copernicus.corrections.planning`); the score-level correction families and their registry, grouped cross-fitting, the estimate-level estimators, the repeated-study check, and the battery that compares the score-level corrections out of sample. Every name below is imported from `copernicus.corrections`.
