# copernicus.corrections

Human sampling of whole groups, with the fingerprint that binds a draw to its table (`copernicus.corrections.sampling`), the draw file that keeps a draw (`copernicus.corrections.draw_files`) and the variation of the number of texts over whole-group draws, with the threshold of its warning (`copernicus.corrections.group_sizes`); the sample-size planner (`copernicus.corrections.planning`); the score-level correction families and their registry, grouped cross-fitting, the estimate-level estimators, the repeated-study check, and the battery that compares the score-level corrections out of sample. Every name below is imported from `copernicus.corrections`.
